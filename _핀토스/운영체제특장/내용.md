## I/O handling 방법

```
polling

interrupt
: CPU한테 interrupt를 날리고, 하던 일을 멈춘다(고 표현함)

실제로는 콜이 된다라고 표현해야함

bus는 CPU가 컨트롤
direct memory access
: CPU가 아닌 device에게 컨트롤을 넘기는 것
: CPU가 I/O 컨틀롤러한테 Memory 어디서부터 어디까지 옮겨라는 작업을 맡길 수 있음
: storage의 controller한테 시키는 것 (버스를 안 쓰는 동안)
: 다 끝나고 나면 interrupt
```
