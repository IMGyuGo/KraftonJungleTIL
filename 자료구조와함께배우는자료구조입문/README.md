# 모르는 파이썬 개념 정리

## \_\_name\_\_이란

```
파이썬 파일이 실행될 떄 자동으로 만들어지는 변수

직접 실행시 : "__main__"
다른 파일에서 import 시 : "파일이름"
```

```py
def add(a, b) :
  return a + b

if __name__ == "__main__" :
  print(add(3,5))
```

```
-> 만약 import된다면, 아래 print는 실행되지 않음
-> 실행 파일일 경우만 실행
```

## \_\_init\_\_()함수란

```
클래스로 객체를 만들때 자동으로 실행되는 초기화 함수
보통 객체의 초기 상태(변수)를 설정할 때 사용
```

```py
class Person :
  def __init__(self) :
    print("객체가 생성됨")
p = Person()

# 실행 결과
"""
객체가 생성됨
"""
```

## 시퀀스형이란

```
리스트형, 바이트 배열형, 문자열형, 튜플형, 바이트열형

[1,2,3,4] -> 리스트 형
bytearray(b'testSample') -> 바이트 배열형
test -> 문자열 형
(1,) or (1,2,3) -> 튜플
ABC일 경우 -> [65, 66, 67]로 바이트로 저장되어있는 상태
```

```
- 바이트 배열형(bytearray)
  - 즉 바이트란 말 그대로 1바이트
  - byte array는 바이트들을 저장하는 배열
```

```python
# 앞에 b가 붙으면 byte 문자열이라는 의미
print(b'testSample')

# 저장
"""
t   e   s   t   S  a  m   p   l   e
116 101 115 116 83 97 109 112 108 101
"""

# 위 처럼 아스키 코드 값으로 저장된다. (문자열을 넣게된다면)

# ord 함수는 문자열을 아스키 코드로 변경해주는 함수
ord('a')
```

## Mutable 시퀀스형이란

```
MutableSequence ⊂ Sequence

시퀀스중에서 수정가능한 시퀀스를 의미
```

## 파이썬의 얕은복사와 깊은복사

```py
x = [[1,2,3], [4,5,6]]

y = x.copy() # 얕은 복사
x[0][1] = 9

"""
얕은복사 시
x => [[1,9,3], [4,5,6]]
y => [[1,9,3], [4,5,6]]
"""

y = x.deepcopy() # 깊은 복사
x[0][1] = 9

"""
깊은복사 시
x => [[1,9,3], [4,5,6]]
y => [[1,2,3], [4,5,6]]
"""
```
