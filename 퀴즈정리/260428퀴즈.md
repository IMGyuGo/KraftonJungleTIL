2. 다음 C 코드에서 발생하는 메모리 누수(memory leak)를 찾고, 해결 방안을 제시하시오.

#include <stdio.h>

#include <stdlib.h>

typedef struct {

    int data;

    char *description;

} item;

item* create_item(int data, const char *desc) {

    item *new_item = (item *)malloc(sizeof(item));

    if (new_item == NULL) {

        return NULL;

    }



    new_item->data = data;

    new_item->description = (char *)malloc(strlen(desc) + 1);

    strcpy(new_item->description, desc);



    return new_item;

}

int main() {

    item *myItem = create_item(5, "Test Item");

    printf("Item: %d, Description: %s\n",

      myItem->data, myItem->description);



    // 다른 작업 수행



    free(myItem); // 메모리 해제

    return 0;

}

```
멀티 프로세스는 브라우저 같이 웹을 띄어놓을 때 웹창을 늘려서 이동하는 것과 같이 Concurrency하게 동작하는 것이고
멀티 쓰레드는 여러개의 병렬 작업 예로 들면 노래도 듣고 메모장에 일기도 쓰고 즉, 한번에 여러가지를 수행할 경우 사용
```

```
멀티프로세스는 각 프로세스가 독립된 주소 공간을 가지므로 안정성이 높다.

하지만 공유 자원에 대한 동기화가 필요하고, 하나의 스레드 문제가 전체 프로세스에 영향을 줄 수 있다.
```

4. 데드락의 개념에 대해 설명하시오 .

```
이미 죽은 프로세스가 락을 계속 잡고 있는 것
따라서 쓸 데 없는 자원이 계속 쌓이고 문제가 발생함
```

```
데드락은 “죽은 프로세스가 락을 잡는 것”이 아니라, 여러 프로세스/스레드가 서로가 가진 자원을 기다리면서 아무도 진행하지 못하는 상태야.

스레드 A는 lock1을 잡고 lock2를 기다린다.
스레드 B는 lock2를 잡고 lock1을 기다린다.
둘 다 상대방이 가진 락을 기다리므로 영원히 진행하지 못한다.
이 상태를 데드락이라고 한다.
```

5. Semaphore와 Mutex의 특징과 주요 차이점은 무엇인가?

```
좀 더 찾아서 정리해보겠습니다.
```

```
Mutex는 한 번에 하나의 스레드만 공유 자원에 접근하도록 막는 동기화 도구이다.
보통 lock을 건 스레드가 unlock도 해야 한다.

Semaphore는 내부에 정수 값을 가지고 있으며, 여러 개의 자원 개수를 관리할 수 있다.
값이 1인 binary semaphore는 mutex처럼 사용할 수 있고,
값이 N이면 최대 N개의 스레드가 동시에 접근할 수 있다.

주요 차이점은 mutex는 상호 배제를 위한 락이고,
semaphore는 자원의 개수나 실행 순서를 제어하는 데 더 일반적으로 사용된다는 점이다.
```
