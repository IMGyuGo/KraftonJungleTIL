```
잘 모르겠습니다.
```

```
MLFQS (Multi Level Feedback Queue Scheduler)

- 다양한 CPU 사용 패턴을 가진 프로세스를 공정하게 스케줄링하기 위해 사용
- I/O-bound 프로세스는 빠르게 반응하도록 높은 우선순위 유지
- CPU-bound 프로세스는 점점 낮은 우선순위로 내려감
- starvation을 방지하면서도 responsiveness를 높임

CPU 사용량에 따라 동적으로 우선순위를 조정하기 위해 사용
```
