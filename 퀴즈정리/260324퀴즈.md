   (최악 : O(n^2)) 뽑은 값이 항상 최소일 경우 2개로 분리를 할 때,
   기준 값보다 큰 집합, 작은 집합 2개로 나눠서 탐색 시간을 O(nlog(n))으로 줄이는 건데 항상 작은거를 뽑을 경우 모든 값을 비교하게 되므로

```
이진 탐색 트리는 균형이 잡혀 있으면 탐색, 삽입, 삭제가 O(log n)이지만,

```

5. 트리 구조가 컴퓨터 시스템에서 활용되는 예를 두 가지 제시하고, 각각 해당 구조가 적합하다고 생각하는 이유를 서술하시오.

DOM 구조 - Tag를 키값으로 두고 부모와 자식간의 관계를 갖고 있다. 특히 트리구조에서 객체가 변했을 때 탐색을 하기에 용이하다.

네트워크 망 - 인터넷 통신망이 라우터를 기준으로 세부적으로 private IP를 할당받고, 그것의 주소를 찾아가기에 트리구조가 용이하다고 생각이 된다.

```
웹 페이지의 DOM(Document Object Model)은 HTML 요소들이 부모-자식 관계를 가지므로 트리 구조로 표현된다.
이 구조는 특정 요소를 탐색하거나, 하위 요소를 묶어서 관리하거나, 부분적으로 변경 사항을 반영하기에 적합하다.

컴퓨터의 파일 시스템은 폴더와 파일이 계층적으로 구성되므로 트리 구조와 잘 맞는다.

```
