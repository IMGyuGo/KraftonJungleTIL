1. 학생을 학번으로 사물함에 배정하는 학교를 비유로 해시 충돌을 설명하시오.

학생 학번 : key, 사물함 번호 : value로 key가 중복되면 해시 충돌이 발생한다.
즉, 학생의 학번은 고유한 숫자

- 정답
  해시 충돌은 key가 중복되는 것이 아닙니다.
  오히려 **서로 다른 key인데 같은 해시 결과(같은 저장 위치)**가 나오는 경우예요.

학교 비유로 바르게 말하면
학생의 학번 = key
사물함 번호 = 해시 함수 결과
학번은 원래 서로 다를 수 있음

그런데 어떤 규칙으로 사물함 번호를 정할 때,
다른 두 학생이 같은 사물함 번호를 배정받으면 해시 충돌

2. 파이썬 heapq 모듈로 최대 힙을 구현하려고 한다. 이 때 가장 간단한 방법은 무엇일까?

heapq.max() - 기억 안남..

- 정답
  파이썬 heapq는 기본적으로 최소 힙(min-heap) 입니다.
  가장 간단하게 최대 힙처럼 쓰는 방법은 값에 음수(-)를 붙여 넣는 것이에요.
  heapq는 기본적으로 최소 힙만 지원하므로, 최대 힙을 구현하려면 값을 넣을 때 음수로 바꿔서 저장하고 꺼낼 때 다시 음수 부호를 반대로 바꾸는 방법이 가장 간단하다.

```py
import heapq

heap = []
heapq.heappush(heap, -10)
heapq.heappush(heap, -30)
heapq.heappush(heap, -20)

print(-heapq.heappop(heap))  # 30
```

4. 고정 크기 배열(예: 크기 10)만 사용하여, 요소를 이동시키지 않고 O(1)로 삽입/삭제가 가능한 큐를 설계한다면 어떻게 해야할까? 설계 방식을 설명하고 간단하게 파이썬 혹은 수도 코드로 enque, deque 함수를 만들어 보시오.

```py
staticList = [0] * 10

def enque(loc, val) :
  firstList = staticList[:loc]
  lastList = staticList[loc:]

  firstList.append(val)
  staticList = firstList+lastList

def deque(loc, val) :
  firstList = staticList[:loc+1]
  lastList = staticList[loc+1:]

  firstList.pop()
  staticList = firstList+lastList
```

2개의 스택으로 나눠 첫번째 스택의 뒤를 추가하거나 삭제하여 다시 합친다.

- 정답 (원형 큐)

```py
SIZE = 10
queue = [None] * SIZE
front = 0
rear = 0

def is_empty():
    return front == rear

def is_full():
    return (rear + 1) % SIZE == front

def enqueue(value):
    global rear
    if is_full():
        print("큐가 가득 참")
        return
    queue[rear] = value
    rear = (rear + 1) % SIZE

def dequeue():
    global front
    if is_empty():
        print("큐가 비어 있음")
        return None
    value = queue[front]
    queue[front] = None
    front = (front + 1) % SIZE
    return value
```

5. 배열에서 특정 값을 찾기 위해 처음부터 끝까지 순차적으로 탐색하는 경우의 시간 복잡도를 빅오(Big-O) 표기법으로 작성하고, 그 이유를 함께 설명하시오.

O(N) -> idx 0부터 순차적으로 찾아갈 때,
n이라는 특정 값을 찾기 위해서는 0부터 n-1번까지 idx를 살펴봐야 하므로

```
배열의 처음부터 끝까지 하나씩 비교
최악의 경우 원하는 값이 맨 끝에 있거나 아예 없음
그래서 최대 N번 비교
따라서 시간복잡도는 O(N)
```
