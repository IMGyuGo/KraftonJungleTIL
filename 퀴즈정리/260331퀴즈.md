```
CPU가 메모리를 Read/Write 할 때, 적재(메인메모리에서 PC로 덮어쓰기), 저장, 연산, 점프 과정을 반복하는데, 캐시 메모리를 두어 자주 사용되는 메모리는 먼저 캐시에서 읽어들여 캐시 힛트를 통해 빠르게 받아들이는 게 속도측에서 많이 좋다.
프로세서는 Register와 L1,L2,L3 캐시로 킬로바이트에서 메가바이트의 데이터를 처리(빠른데 용량이 작고 가격도 비싸다)

```

```
CPU와 메모리 간 속도 차이를 줄이기 위해, 자주 사용하는 데이터를 가까운 캐시에 저장하여 접근 지연(latency)을 줄이기 위함이다.

```

멀티프로세스 방식이 더 유리하다.
