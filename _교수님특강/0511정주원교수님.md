# CPU는 하나인데 여러개인것처럼 흉내(Thread, time sharing, space sharing)
```
코어의 추상화 = Thread
- 코어가 하나인데 여러개인 것처럼 흉내
- 그렇기 때문에 thread
- 쓰레드 끼리는 서로 메모리를 공유 (같은 컴퓨터 안의 코어만 다를 뿐)

컴퓨터의 추상화 = Process
- Process 끼리는 메모리가 서로 달라야 함(서로 별도의 메모리)
```
