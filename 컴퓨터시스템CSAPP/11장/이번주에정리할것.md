- dup2()

```
유닉스 및 유닉스 계열 운영체제에서 파일 디스크립터를 복제하는 시스템 콜(운영체제 커널이 제공하는 서비스를 사용하기 위해 애플리케이션이 커널에게 요청하는 인터페이스)

int dup2(int oldfd, int newfd);

oldfd : 복제할 파일 디스크립터
newfd : oldfd의 내용을 복사할 새로운 파일 디스크립터
-> ex
dup2(fd, STDOUT_FILENO); // 표준 출력을 파일에 리디렉션

STDOUT_FILENO
STDIN_FILENO
STDERR_FILENO

Dup2(fd, STDOUT_FILENO)는 "STDOUT_FILENO가 가리키는 대상을 fd와 같게 바꾼다"는 뜻
즉 serve_dynamic의 자식 프로세스에서 이걸 해두면, 그 다음 execve()로 실행된 CGI 프로그램의 표준출력 stdout이 클라이언트 소켓으로 연결됨. 그래서 CGI가 printf("Content-type: text/html\r\n\r\n...")를 하면 그 내용이 브라우저로 감.

조금 더 정확히 말하면 dup2(oldfd, newfd)는 newfd를 닫고, 그 번호가 oldfd와 같은 열린 파일을 가리키게 만듬.
예를 들어 fd가 소켓 5이고 STDOUT_FILENO가 1이면, 실행 뒤에는 1번이 소켓을 가리키게 됨. 그러면 write(1, ...), printf(...), puts(...)가 전부 소켓으로 나감. 이후 fd 자체는 닫아도 되고, 1번이 살아 있으니 출력은 계속 가능.

STDOUT_FILENO 말고도 대표적으로 3개가 있습니다.

STDIN_FILENO = 0
STDOUT_FILENO = 1
STDERR_FILENO = 2
그래서 이런 것도 가능합니다.

Dup2(fd, STDIN_FILENO)
클라이언트 소켓을 표준입력으로 연결
Dup2(fd, STDOUT_FILENO)
클라이언트 소켓을 표준출력으로 연결
Dup2(fd, STDERR_FILENO)
에러 출력도 같은 소켓으로 보내기
```
