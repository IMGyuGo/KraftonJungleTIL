# 모르는 것 정리

1. 어셈블리어의 %rbx

```
CPU 레지스터 중 하나
특히 x86-64 아키텍처에서 사용하는 64비트 일반 목적 레지스터

레지스터란
- CPU 안에 있는 초고속 변수(저장공간)

%rbx = general-purpose register (64bit)
- 64비트 레지스터
- 정수, 주소 등 아무거나 저장 가능
- 이름의 의미
    - r : register
    - bx : 옛날 x86에서의 이름 계승

callee-saved register
함수를 호출 했을 때
%rax, %rcx, %rdx -> 마음대로 써도 됨(caller-saved)
%rbx -> 값을 반드시 복구해야 함
```
